# TrackOlap Local Connector 1.0.5 — Windows upgrade permissions

Windows evaluation preview with x64, x86 and ARM64 standalone setup EXEs.

## Changes

- Replaces the recursive `icacls` setup step that could fail with `exit status 5` on an
  upgrade. Setup applies a complete private access policy at once, preserving access
  for the background service, SYSTEM and administrators.
- Repairs inaccessible state files from an interrupted older upgrade using temporary
  Windows backup/restore privileges after administrator approval. Existing pairing,
  configuration, logs, file contents and ownership are retained.
- Refuses linked state paths and hard-linked files; reports the affected operation and
  path if repair fails. The service stays stopped on failure.
- Shows **Application version** in the tray window title and footer in every state,
  including before pairing and while the service is unavailable. Configured status
  separately shows the background agent version.

## Upgrade

Run the setup matching your existing architecture and approve the administrator prompt.
Do not reset or delete your configuration to work around the older permission error.
For MSI installations or an architecture change, follow the
[Windows installation guide](https://github.com/Kaptune/trackolap-local-connector/blob/main/WINDOWS_INSTALL.md).

## Validation and availability

Go format, vet and the full host test suite passed. Windows permission regression tests
and tray code cross-compile for x64, x86 and ARM64. The elevated Windows regression suite
covers inaccessible SYSTEM-owned state, preserved content/ownership, repeat upgrades,
new-file inheritance, clean installation and link rejection. That suite has not been
executed on Windows; installation and permission repair still need Windows runtime
validation. See `BUILDINFO.json` for build details.

Installers are unsigned evaluation previews. macOS/Linux remain on their existing
multi-platform release, and MSI packaging remains pending. Releases are manual.
See [Downloads](https://github.com/Kaptune/trackolap-local-connector/blob/main/DOWNLOADS.md)
and the [platform guide](https://github.com/Kaptune/trackolap-local-connector).
