# TrackOlap Local Connector 1.0.6 — HTTP/TCP transport update

Evaluation prerelease for Windows, macOS and Linux. All packages in this release use
the same updated agent source.

## Changes

- Removes the obsolete dedicated command-poll request and its periodic source timers.
  The agent no longer calls `/connector/1/commands/poll` or starts the legacy command
  WebSocket connection.
- Keeps pairing, heartbeats, configuration updates, approved-target management and
  generic HTTP/TCP tests working through their existing APIs.
- HTTP/TCP relay discovery and data exchange continue over authenticated outbound
  HTTPS. Removing command polling does not remove tunnel discovery.
- Existing queued legacy work can still arrive in heartbeat, configuration or result
  responses; it no longer has a separate command-discovery loop.
- Windows setup retains the service/tray, Stop Application, Reset, version display and
  upgrade-permission repairs from the previous desktop releases.

## Upgrade and backend compatibility

Install these agents **before** deploying a backend that removes the old command-poll
route. Older agents continue to request that route and may report repeated errors after
it is removed. This agent also works while that route is still present on the backend.

Run the installer matching your existing platform and architecture. Preserve the state
directory and existing pairing; a routine upgrade does not require Reset or a new code.
For Windows MSI installations or architecture changes, follow the
[Windows guide](https://github.com/Kaptune/trackolap-local-connector/blob/main/WINDOWS_INSTALL.md).

After upgrading, confirm version 1.0.6, **Online** status, a recent heartbeat, and a
successful HTTP/TCP test against an approved target.

## Available packages

- Windows x64, x86 and ARM64: signed service/tray setup EXEs only.
- macOS Intel and Apple silicon: PKGs, portable binaries and TAR.GZ archives.
- Linux AMD64 and ARM64: DEB and RPM packages, portable binaries and TAR.GZ archives.
- SHA-256 checksums and `BUILDINFO.json` with the exact source revision and validation scope.

Windows installers and their embedded service/tray executables are signed as
**Kaptune Media India Private Limited**, using SHA-256 and Sectigo RFC 3161 timestamps.
macOS packages have no Developer ID signing or notarization; Linux packages remain
unsigned. These are evaluation builds with manual upgrades.

## Signed Windows package refresh

The Windows setup assets for this version now contain signed service and tray binaries
and are themselves signed. The application version and source revision are unchanged.
Portable Windows EXEs/ZIPs and their checksum files have been removed from this release.
Download the updated `SHA256SUMS`; hashes from the earlier unsigned downloads no longer
match the signed Windows installers. macOS/Linux build files are unchanged.

## Validation

The full Go tests, format checks and vet passed. Agent/API/tunnel/supervisor race tests
and 100 related backend tests passed. All seven agent architectures and the three
Windows service/tray/setup combinations were compiled. Archive and installer payloads,
platform metadata and checksums were verified. All nine Windows executable signatures
and timestamps were verified with osslsigncode, and each signed setup was checked to
contain its exact signed service/tray payloads.

Installation, upgrade, reboot and tray behavior were not exercised on Windows for this
release. macOS and Linux installer execution was not exercised. Package inspection and
cross-compilation do not substitute for installation testing.
