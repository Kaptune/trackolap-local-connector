# TrackOlap Local Connector 1.0.7

Connect TrackOlap to approved HTTP and TCP services on your local network.

## What's improved

- More reliable command retries after interruptions.
- Existing pairing and configuration are preserved when upgrading.

## Downloads

- **Windows:** x64, x86 and ARM64 installers with a background service and tray app.
- **macOS:** Intel and Apple silicon packages.
- **Linux:** AMD64 and ARM64 DEB/RPM packages.

[Choose your download](https://github.com/Kaptune/trackolap-local-connector/blob/main/DOWNLOADS.md) ·
[Installation guide](https://github.com/Kaptune/trackolap-local-connector/blob/main/INSTALLATION.md)

## Upgrade

Install the package matching your current operating system and architecture. No reset or
new pairing code is needed for a normal upgrade. Afterwards, check that the connector
shows **Online** in TrackOlap and test an approved HTTP/TCP target.
