# TrackOlap Local Connector 1.0.7 — Command retry reliability

Evaluation prerelease for Windows, macOS and Linux.

## Changes

- Returns the execution lease supplied by TrackOlap with every command result, including
  chained commands and commands that cannot be delivered to a local worker.
- Allows the platform to distinguish a current execution from an older attempt, preventing
  a delayed result from closing a replacement attempt after a timeout and retry.
- Preserves compatibility with older backends that do not supply execution leases.
- Retains generic HTTP/TCP connectivity, pairing, heartbeats, approved targets and the
  Windows background service and tray controls.

## Upgrade

Run the installer matching your existing platform and architecture. Normal upgrades retain
pairing and configuration; do not use Reset just to upgrade.

Deploy the compatible backend with mandatory lease validation disabled, upgrade the agent
fleet, then enable `-Dconnector.result.lease.required=true` on every API instance after
confirming legacy results have stopped. Enabling it before upgrading agents rejects their
command results. Older agents remain subject to the late-result race during this transition.

After upgrading, confirm version 1.0.7, Online status, a recent heartbeat and a successful
HTTP/TCP test against an approved target. Upgrades remain manual.

## Downloads and signing

- Windows x64, x86 and ARM64: service-and-tray setup EXEs only, signed as
  **Kaptune Media India Private Limited**, with SHA-256 and Sectigo RFC 3161 timestamps.
- macOS Intel and Apple silicon: PKGs, binaries and TAR.GZ archives; no Developer ID
  signing or notarization.
- Linux AMD64 and ARM64: DEB/RPM packages, binaries and TAR.GZ archives; unsigned.
- SHA-256 checksums and BUILDINFO.json identify the artifacts and source revision.

## Validation

See BUILDINFO.json for completed build and test checks. Installation, reboot, upgrade and
tray runtime behavior have not been exercised on Windows for this release. macOS/Linux
package installation has not been exercised. This is an evaluation prerelease.
