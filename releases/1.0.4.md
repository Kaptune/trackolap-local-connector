# TrackOlap Local Connector 1.0.4 — Windows Stop and Reset

Windows evaluation preview with x64, x86 and ARM64 standalone setup EXEs.

- **Stop Application** stops the background service and closes the tray app. Configuration is retained. The service can be started manually and still starts after a Windows reboot.
- **Reset** stops the service, waits for its process to exit, removes saved pairing, host, targets and cached work, and restarts unconfigured. A fresh pairing code is required. Logs and remote portal records/history are retained.
- **Start service** is available when the tray cannot reach the background service.
- Stop and Reset require confirmation, defaulting to No, and Windows administrator approval. Cancelling makes no changes. Failed reset cleanup leaves the service stopped.

The ordinary desktop pairing pipe remains limited to status and initial pairing. Privileged lifecycle actions use a separate elevated helper, fixed action names, the installed service registration, and a shared setup-operation lock. Reset supports the standard ProgramData state directory and refuses linked directories; it deletes only known state files.

## Install and validation

Install over the previous setup using the same architecture. Ordinary upgrades preserve configuration. Source revision: `0a9dd11`.

Full Go format/vet/tests, reset and desktop race tests, and Windows cross-vet passed. All three Windows architectures cross-compiled; executable architecture, GUI manifests, embedded installer payloads and SHA-256 checksums were checked. Actual Windows UAC, service lifecycle and tray interactions still require runtime validation. Installers are unsigned evaluation previews. macOS/Linux remain on 1.0.1; MSI packaging remains pending. Builds are manual, without CI/CD.

The backend pending-activation fix described in [1.0.3](https://github.com/Kaptune/trackolap-local-connector/blob/main/releases/1.0.3.md) is still required on affected servers.

## Portal administration update

The matching backend/frontend update adds **Delete** for connectors that have never
sent a heartbeat, including failed paired installations. Previously seen connectors
remain protected. This is a server/portal feature and does not change these installer
binaries. See the current [Windows installation guide](https://github.com/Kaptune/trackolap-local-connector/blob/main/WINDOWS_INSTALL.md)
and [portal deletion instructions](https://github.com/Kaptune/trackolap-local-connector#delete-a-connector-that-was-never-seen).
The documentation attached as release assets is the original build-time snapshot;
linked repository guides include subsequent portal updates.
