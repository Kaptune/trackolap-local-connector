# TrackOlap Local Connector 1.0.1

Evaluation prerelease of the generic HTTP/TCP local connector. All agent binaries are built from source revision `3a7571c870659dd86ddb2d9d0ef5053a1b2e544a` with Go `1.26.5`, with the TrackOlap connector icon and CGO disabled.

## Changes

- Generic TCP transport for approved local service aliases, supporting HTTP requests and other TCP application protocols.
- Portal-managed targets: add/delete aliases, persist changes locally, and report applied destinations through heartbeat. Target changes close existing tunnel connections, so clients may need to reconnect.
- HTTP/TCP traffic diagnostics with local and peer socket IPs, duration, status and connection summaries. Raw TCP payloads are not recorded.
- Compatible with the current portal's generic HTTP request tester and TCP connectivity test. Backend and frontend deployment is required for these controls.

## Downloads

- Windows x64, x86 and ARM64: portable EXE and ZIP agents.
- macOS Intel and Apple silicon: PKG installers, standalone binaries and TAR.GZ archives.
- Linux AMD64 and ARM64: DEB/RPM installers, standalone binaries and TAR.GZ archives.
- `SHA256SUMS`, individual checksum files, and `BUILDINFO.json` with build provenance.

**Windows MSI installers are pending a Windows packaging host and are not included in this release.** Windows ZIP agents run in the foreground using the installation guide; they do not configure a persistent service automatically. No older MSI has been relabeled as 1.0.1.

## Validation

- `make verify` passed: formatting, vet and the full Go test suite.
- All seven binaries were checked for platform/architecture and CGO-disabled metadata. Every archive's executable matches its standalone binary.
- Both macOS PKGs were checked for version, architecture and embedded executable. Both DEBs were checked for version/architecture and embedded executable; both RPM embedded executables were compared with the release binaries.
- The final AMD64 DEB was installed on the prepared Linux test host. Pairing configuration was preserved; the connector service, local HTTP simulator and MySQL checks passed.
- macOS and Windows installation/pairing have not been exercised for this release; package inspection is not an installation test. ARM64 Linux installation is also not yet exercised.

## Requirements and limitations

The backend needs the Local Connector feature enabled, the latest target-management APIs, and `connector.tcp.enabled=true` for generic tests. The frontend must include the generic connector detail page. On a backend behind a load balancer, tunnel exchanges must reach the owning backend instance because sessions are process-local.

This is an **unsigned evaluation release**: no Windows Authenticode signature, no macOS Developer ID signature/notarization, and no Linux package signature. OS security checks may block unsigned downloads. Automatic updates remain disabled; installation and upgrades are manual. These builds have no desktop tray UI.

HTTP/TCP transport does not implement database queries or application-specific synchronization by itself. Use the generic tests to verify an approved service is reachable. Keep pairing codes and local configuration private.

See the [installation guide](https://github.com/Kaptune/trackolap-local-connector#readme). Builds and publishing remain manual; no CI/CD was added.
