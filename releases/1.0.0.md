# TrackOlap Connector 1.0.0

Initial evaluation build of the TrackOlap local connector. Tally party ledgers can be synchronized into TrackOlap customers using an enrolled background agent.

## Included targets

- Windows: x64, x86 and ARM64 binaries, ZIP archives and MSI installers.
- macOS: Apple silicon and Intel binaries, TAR.GZ archives and PKG installers.
- Linux: AMD64 and ARM64 binaries, TAR.GZ archives, DEB and RPM packages.
- SHA-256 checksums and build provenance in `BUILDINFO.json`.

## Build and validation

Application source revision: `17a09b755668` (short revision). Go toolchain: `go1.26.5`. The application working-tree difference was confined to its release workflow, not runtime code. `make verify` passed, including formatting, vet and all 17 tested Go packages.

Package metadata and archive payloads are checked during packaging. Actual installation, pairing and Tally synchronization on customer operating systems require deployment testing; compilation is not an end-to-end installation test.

## Known limitations

- Unsigned Windows installers; unsigned and unnotarized macOS packages.
- Automatic updates disabled; no pinned release verification key.
- Windows installer terms are inherited placeholder text and need approved replacement before production release.
- Background-service builds do not include a desktop tray icon.
- Concurrent console/doctor processes may conflict with the service's database lock.
- Tally is the implemented data connector; SQL/ODBC entries are not implementations.
- Scheduled sync and server-side WebSocket notifications are not implemented. Use explicit sync commands; long-polling delivers work.
- Server-side expired-command recovery is not scheduled, and deployment must verify required Mongo indexes.

These limitations are why the initial release is prepared as an evaluation prerelease. See the repository README for installation and pairing.
