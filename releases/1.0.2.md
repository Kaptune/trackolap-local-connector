# TrackOlap Local Connector 1.0.2 — Windows desktop preview

Windows-only evaluation preview: self-contained setup EXEs for x64, x86 and ARM64.
macOS/Linux downloads remain on 1.0.1. No MSI is included in this preview.

## Windows experience

- Setup installs the background agent as an automatic Windows service, with restart-on-failure recovery.
- A separate tray app starts at sign-in. Closing its window or signing out does not stop the service.
- Red icon before pairing; green when configured. Click to open a small native window.
- Before pairing: API host, pairing code and **Start**.
- After pairing: host, connector ID, running/connection status, last successful sync, last heartbeat and agent version.
- Last successful data sync survives a service restart. Heartbeat and TCP test times are not mislabeled as data syncs.
- Updates preserve pairing. Windows Apps settings provides uninstall, which preserves configuration for reinstall.

The desktop app does not read the service's credentials or database. It verifies the service's Windows process identity before sending a pairing code over a local-only named pipe. Already-configured agents cannot be paired again through the tray.

## Validation and limits

Source revision: `a8215b9`. Go toolchain: `go1.26.5`. All builds are CGO-free.

The full Go format/vet/test suite passed. Pairing/status/security and last-sync persistence tests passed with race detection. Windows-only code passed cross-platform vet, and all three architectures cross-compiled. Executable architecture, Windows GUI subsystem, asInvoker manifest, exact embedded service/tray payloads, and SHA-256 checksums were verified.

**No Windows machine was available for runtime testing.** Installation, UAC, standard-user pairing, reboot/login, Explorer restart, service crash recovery, upgrade and uninstall still require Windows validation. These installers are unsigned, and Windows or enterprise security policy may block them. They are evaluation previews, not production-validated packages.

See [Windows installation instructions](https://github.com/Kaptune/trackolap-local-connector/blob/main/WINDOWS_INSTALL.md). Builds remain manual; no CI/CD was added.
