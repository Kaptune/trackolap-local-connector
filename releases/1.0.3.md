# TrackOlap Local Connector 1.0.3 — Windows pairing fixes

Windows evaluation preview with x64, x86 and ARM64 standalone setup EXEs.

- Keep the API host and pairing code after a failed attempt; clear the code only after confirmed configuration.
- Show distinct, credential-safe messages for API rejection, response, server, rate-limit, network and timeout failures. Retain errors across status refreshes.
- Record the same safe diagnostic category in the service log.
- Preserve configured status if a duplicate pairing request arrives.

## Backend requirement and recovery

A backend pending-activation bug can mark a connector ACTIVE but return enrollment failure, leaving the agent without credentials and the portal Offline. Deploy the backend activation-result fix before retrying. Upgrading the Windows installer alone cannot resolve that server bug. Once deployed, create a fresh connector/code for affected unconfigured installations; consumed codes cannot be reused.

Run this installer over the existing installation of the same architecture. Existing configuration is preserved. Already-configured working connectors need no new code.
